# Dashboard UI

A sales and revenue tracking dashboard built with **React 19**, **Vite**, and **Tailwind CSS**.

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Tech Stack

**React** · **Vite** · **Tailwind CSS** · **ESLint**

## Project Structure

```
src/
├── components/   # UI components (Sidebar, Topbar, Dashboard)
├── layouts/      # Page layouts
├── pages/        # Route pages
└── styles/       # Global styles
docs/             # Design documentation
```
